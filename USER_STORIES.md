# User Stories — Personal Finance Tracker

1. As a new user, I want to sign up with a username, email, and password, so that I can create my personal account.
2. As a returning user, I want to log in with my email and password, so that I can access my saved financial data.
3. As a user, I want to see a clear error message when I enter invalid signup details, so that I know what needs to be fixed.
4. As a user, I want to see a clear error message when I enter incorrect login credentials, so that I understand why I can't log in.
5. As a user, I want to view a home screen listing all my transactions, so that I can quickly see my financial activity at a glance.
6. As a user, I want to tap on a transaction to view its full details, so that I can review a specific income or expense.
7. As a user, I want my transactions to be saved locally on my device, so that my data persists even after I close the app.
8. As a user, I want to see live currency exchange rates fetched from an external API, so that I can understand my expenses in other currencies.
9. As a user, I want to access a settings screen where I can manage notifications and app preferences, so that I can customize my experience and receive budget alerts.
